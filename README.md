# SQUID 3D mesh gallery

Interactive viewer of the 3D (tetrahedral) InductEx/TTH meshes of the SQUID flux-port layouts.
Open https://hiroking0.github.io/squid-3d-mesh/ , pick a device, then drag to rotate, right-drag to pan, scroll to zoom.

Generated by `3_code/34_mesh_viewer_export.py` (squid_sim project): `data/*.part1.txt` hold each mesh's outer
surface (gzip + base64), `devices.json` the list.
